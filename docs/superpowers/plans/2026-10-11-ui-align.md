## Global Constraints

- **Tokens win over mockup literals.** When an artboard's hex differs from tokens.json (#16A34A vs success #00a63e, #A3A3A3, old amber #92400E/#FCD34D), use the token. The tokens are the user's stated rule: all spacing, radius, type and colour come from tokens.
- **Type scale.** With the default font size 14, the scale is numerically the same as today. Only the default text size changes from 13 to 14 (user decision):
  - Native: `Xs f-3, Sm f-2, Base f-1, Body f, Lg f+1, Title f+2, Xl f+4, X2l f+6, Display f+15`, and `mygo th.FontSize = Body`.
  - Web: root font = f; `--text-xs 1rem-3px, sm 1rem-2px, base 1rem-1px, md 1rem, lg 1rem+1px`.
  - The default setting is `FontSize: 14`, with options 13/14/15/16.
  - Stored settings get a one-time migration: blobs without `SettingsVersion >= 2` get `FontSize++`, so every named size stays the same for existing users.
  - Brand moves 17 → 20 (X2l) and Heading 19 → 18 (Xl), as the design shows.
- **Out of scope** (feature gaps, later plans, no UI stubs):
  - Model capability split (生成/判断, interface formats, 用途 section, TypeSafe/Decisions).
  - Scheduled send.
  - Time-based sync ranges and 邮箱行为 folder roles/purge.
  - Smart views.
  - Search filter chips (account/sender/time).
  - Move to junk.
  - 始终信任此发件人.
  - Quick-reply kind labels.
  - Plugin-card hint semantics.
  - Plugin tags on list rows.
  - Settings search.
  - 繁體中文/日本語 UI languages.
  - 只通知智能视图里的邮件.
  - Session-scoped "本次对话都允许".
  - Wit `+`/`@` mention.
  - Multi-turn undo history in the panel.
  - Model-written review summary.
  - Quoted injected text in the suspect note.
  - `[n]` inline citation links.
  - Folder counts ("6 个文件夹").
  - Sending from the drafts pane.
  - Signature images (插入图片): compose sanitize strips `data:` and sending would need inline parts.
  - Rich signature rendering inside the compose window, which keeps showing it as plain text.
  - Rounded or padded highlight marks: `ui.Span` has a background only.
  - A live drafts pane while the window edits: there is no draft-changed event, so it refreshes when the window closes.
  - Per-account last-sync time after a restart: kept in memory only.
  - 添加附件 remedy on plugin warnings.
  - 与收件人相同的语言 auto entry.
- **No function lost.** Where the design drops an existing control, the control is kept, moved to the nearest sensible place, and ledgered. This covers:
  - General settings' AI and 邮件 sections.
  - The reader's star, mark unread and ⋯ menu.
  - 丢弃草稿 and the send-trust note in compose.
  - Manual-server security and username fields in onboarding.
- **Copy.** Chinese strings come from the design verbatim. Add en.go counterparts for every new key. Web strings go through `webui/strings.go`.
- **Tests.** Each task runs `go test ./...` and, for web tasks, `cd web && bun run test && bun run typecheck`. Existing tests that assert old copy or layout are updated to the new values, not deleted.
- **Every new size is a named constant in `internal/theme/theme.go`.** `TestNoSizeLiterals` (`app/sizes_test.go`) must stay green. Each task that adds sizes also touches theme.go. Off-scale type such as the mockup's 22 px mono uses the nearest step (`X2l`), ledgered.
- **Kit API names** are fixed here:
  - `kit.DestructiveOutline` (a bare Variant constant);
  - `kit.TabsUnderline(c, sel, labels...)` (a separate func, since Tabs is variadic);
  - `kit.DialogWide(...)` (the 5-arg `kit.Dialog` is unchanged);
  - `kit.AlertAction(c, kind, label, onClick)`;
  - `kit.ButtonGroup` built from Ghost `IconButton`s, which already carry tooltips via `overlay.go`'s `tooltip`;
  - trailing content in an input is a `Bare` input inside a bordered Row (no new InputOpts);
  - settings selects get a `kit.SelectOpts{Radius, MinWidth, MaxWidth, Flat}` variant, `kit.SelectWith`.
- Do not touch the untracked `assets/AppIcon.icon/`, `assets/.DS_Store` or `output/`.

## Review Focus

1. **Dark theme.** Every artboard is light only. New colours come from tokens that have dark values:
   - Highlight uses `Highlight` + `HighlightText` (neutral-950 in both themes) — Task 4.
   - Status chips — Tasks 9 and 11.
   - Theme thumbnails — Task 8.
   - Each of these tasks asserts its dark colours.
2. **Font-size setting at 13 and 16.** Layout must not clip:
   - settings rows (≥ 48 = pad 8 + control 32 + pad 8) — Task 7;
   - the reader toolbar groups — Task 6;
   - the thumbnails — Task 8.
   The assertion uses `ui.Tester.Find` layout boxes: label box bottom ≤ row box bottom, and label box right ≤ control box left.
3. **Search highlight on any text.** Matching is case-insensitive and rune-safe (`unicode.SimpleFold` per rune, never indices from a lowered string). "C++", "", "邮件邮件", mixed case, "İstanbul"/"i" and "K"/"k" (Kelvin sign) must not panic or mis-slice — Task 4.
4. **Drafts pane while the compose window edits the same draft.**
   - "编辑中" shows while the window is opening or open, and clears when it closes.
   - An empty draft deleted on close disappears from the pane.
   - Deleting from the pane closes the window through `DraftDeleted`.
   - Task 5 tests all three.
5. **The signature editor round-trip.** Task 10 tests all three:
   - Legacy plain text, including `Bob <bob@x.com>` and newlines, renders escaped.
   - Editor HTML is marked, sanitized and stripped of godwit markers.
   - Dirty HTML for account A lands in A when settings switch to B, and B is untouched. Closing the window flushes the pending save.

  - the Plate setup in `web/src/compose/editor/Editor.tsx` + `plugins.ts`. Use the marks bold/italic/underline and link; no lists, no images.
- Produces:
  - **Storage format.** Editor HTML is stored in the existing `Signature` string, prefixed with `<!--godwit:html-->`. Anything without the prefix is legacy plain text, including CLI and Local API values.
  - **`core.signatureHTML(sig)`:**
    - With the prefix: strip the prefix, run `mail.StripMarkers`, then `mail.SanitizeCompose`, then wrap in the existing `data-godwit="signature"` div.
    - Without it: escaped plain text, exactly as today.

  - **Bound `webui.SignaturePage`:**
    - `Load(ctx, accountID int64) (string, error)` returns editor HTML. A legacy plain signature comes back as escaped `<p>…<br>…</p>`.

    - Events:
      - `SignatureAccount` (int64) tells the page which account to show;
      - `SignatureFlush` asks the page to save now;
      - `SignatureSaved` acks the flush.
  - **Page protocol:**
    - Edits for account A are always saved as A.
    - On `SignatureAccount(B)`, the page first flushes A's pending save, then loads B.
    - A `Load` reply older than the newest account event is ignored (gen counter).
