# UI Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `internal/kit` into a shadcn-style component library with built-in motion, move every hand-built control in `app/` onto it, guard that with a test, and add a dev-only Kit gallery page.

**Architecture:** `internal/kit` is split into one file per component. Each component styles a mygo `*Base` widget from `theme.Of(c)` tokens and carries its own `ui.ElementTransition`, timed by new theme motion tokens. `app/` stops calling the unstyled mygo primitives, and a source-scanning test enforces it the way `TestNoColorLiterals` does. The gallery is `kit.Gallery`, shown by a `PageKit` route that the rail offers only when `Deps.Dev` is set (from `mygo.IsDev()`).

**Tech Stack:** Go 1.27 (mise), mygo v0.3.7 `ui` (immediate mode, `ui.Tester` for tests), Lucide icons via `internal/icons`, i18n via `internal/i18n`.

**Spec:** `docs/superpowers/specs/2026-10-08-godwit-design.md` §7.0 (design system, the 组件库 / 动效 / 组件预览页 bullets).

## Global Constraints

- `CGO_ENABLED=0` for every build and test. Toolchain: `eval "$(mise env -s zsh)"`.
- Colors only from `theme.Of(c)` tokens (`TestNoColorLiterals` scans `app/` and `internal/kit/`).
- Sizes only from `c.Theme().Space(n)`, `theme.Of(c).Radius`/`.Text` and `internal/theme` constants (`TestNoSizeLiterals` scans `app/`, `internal/kit/`, `internal/richtext/`). New fixed sizes become named constants in `internal/theme/theme.go`.
- User-visible strings go through `i18n.T`, with both `internal/i18n/en.go` and `zh.go`. Exception: the dev-only gallery's own labels may be English literals.
- Durations: `theme.MotionFast = 120 * time.Millisecond`, `theme.MotionBase = 200 * time.Millisecond`; easing is mygo's default ease-out. Never animate when the desktop asks for less motion; mygo's `Transition`/`Animate`/`Loop` already honor `ReduceMotion`, so use only those.
- Menus stay native: `Element.Menu` and `Element.ContextMenu` are not wrapped.
- No new module dependencies.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Reduce motion.** With `Preferences{ReduceMotion: true}` every kit state change lands in the same frame. This is pinned in Task 2 (`TestKitButtonReduceMotion`).
2. **Disabled controls.** A disabled Button/IconButton neither changes color on hover nor clicks. Pinned in Task 2 (`TestKitButtonDisabledInert`).
3. **Selected rows.** A selected SidebarItem/RailButton/Pressable does not fire OnClick, and an unselected one does. Pinned in Task 3 (`TestKitSelectedDoesNotClick`).
4. **Keyboard users get the tooltip.** Focusing an IconButton with Tab shows its tooltip at once, and its accessible label stays the label passed in, which every `h.click(label)` in the app tests relies on. Pinned in Task 3 (`TestKitTooltipOnFocus`).
5. **Dark appearance.** Every component in the gallery renders under `theme.Dark()` without panicking, with the Switch thumb still distinct (existing rule). Pinned in Task 7 (`TestGalleryRendersInBothAppearances`).

### Task 3: Pressable, RailButton, Tooltip; transitions on SidebarItem

**Files:**
- Modify: `internal/kit/surface.go`, `internal/kit/overlay.go`, `internal/kit/button.go`, `internal/kit/kit_test.go`
- Modify: `internal/theme/theme.go` (constants below)

**Interfaces:**
- Consumes: `colors`, `theme.MotionFast` (Task 1).
- Produces:
  - `type PressableOpts struct { Selected, Bordered, Bare bool; OnClick func() }`.
  - `func Pressable(c *ui.Context, o PressableOpts) ui.Element`. A clickable surface for content the caller builds (a card, a tile, a list row): `Justify(ui.Start)`, `Radius(t.Radius.Md)`, the colors transition.
    - `Bordered` adds `Border(theme.Hairline, t.Border)` and `Background(t.Background)`.
    - Hover background is `t.Hover`; `Selected` background is `t.SidebarSelected`.
    - `Bare` skips the hover and selected backgrounds; the caller draws its own selection, as the theme tiles do.
    - OnClick does not fire while `Selected`.
    - Callers add Padding/Gap/Children, and may override Radius/Border after.
  - `func RailButton(c *ui.Context, icon, label string, selected bool, onClick func()) ui.Element`. The rail's square: `Size(theme.RailButton, theme.RailButton)`, centered icon (`theme.IconLg`), `Label(label)`, `Tooltip` (kit), background `t.RailSelected` when selected and `t.Hover` on hover, colors transition. onClick does not fire while selected, as for Pressable and SidebarItem.
  - `func Tooltip(c *ui.Context, anchor ui.Element, text string)`. Styled `ui.TooltipBase`: padding `Space(1)`/`Space(2)`, `Radius(t.Radius.Sm)`, background `t.Primary`, text `t.PrimaryText` at `t.Text.Xs`, with `Transition(ui.ElementTransition{Duration: theme.MotionFast, Enter: &ui.Motion{Y: theme.MotionOffset}, Exit: &ui.Motion{}})`. It also sets `anchor.Description(text)` so assistive technology reads it.
  - `IconButton` now calls `Tooltip(c, b, label)` instead of `b.Tooltip(label)`.
  - `SidebarItem` gains `.Transition(colors(theme.MotionFast))`.
  - New theme constant: `MotionOffset = 4` (DIPs a panel or tip travels as it enters).
