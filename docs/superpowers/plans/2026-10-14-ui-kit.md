# UI Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `internal/kit` into a shadcn-style component library with built-in motion, move every hand-built control in `app/` onto it, guard that with a test, and add a dev-only Kit gallery page.

**Architecture:**
- `internal/kit` is split into one file per component.
- Each component styles a mygo `*Base` widget from `theme.Of(c)` tokens and carries its own `ui.ElementTransition`, timed by new theme motion tokens.
- `app/` stops calling the unstyled mygo primitives; an AST-scanning test enforces this, the way `TestNoSizeLiterals` does.
- The gallery is `kit.Gallery`, shown by a `PageKit` route. The rail offers it only when `Deps.Dev` is set (from `mygo.IsDev()`).

**Tech Stack:** Go 1.27 (mise), mygo v0.3.7 `ui` (immediate mode, `ui.Tester` for tests), Lucide icons via `internal/icons`, i18n via `internal/i18n`.

**Spec:** `docs/superpowers/specs/2026-10-08-godwit-design.md` §7.0 (design system, the 组件库 / 动效 / 组件预览页 bullets).

## Global Constraints

- `CGO_ENABLED=0` for every build and test. Toolchain: `eval "$(mise env -s zsh)"`.
- Colors only from `theme.Of(c)` tokens (`TestNoColorLiterals` scans `app/` and `internal/kit/`).
- Sizes only from `c.Theme().Space(n)`, `theme.Of(c).Radius`/`.Text` and `internal/theme` constants (`TestNoSizeLiterals` scans `app/`, `internal/kit/`, `internal/richtext/`). New fixed sizes become named constants in `internal/theme/theme.go`.
- User-visible strings go through `i18n.T`, with both `internal/i18n/en.go` and `zh.go`. Exception: the dev-only gallery's own labels and sample text are English literals.
- Durations: `theme.MotionFast = 120 * time.Millisecond`, `theme.MotionBase = 200 * time.Millisecond`. Easing is mygo's default ease-out.
- What mygo can animate, and how this plan uses it:
  - `ElementTransition{Colors: true}` moves **background and border colors only** (mygo `transition.go:480`). Text and icon colors change at once.
  - `Position`/`Size` move an element that already existed.
  - `Enter`/`Exit` do **not** play for an element born in the same frame as its parent (`transition.go:284`). So overlays (Dialog, Sheet, Popover, Tooltip, whose panel is born with its layer) appear and vanish at once. Do not add Enter/Exit to them.
  - Transition and Animate honor ReduceMotion. **`Loop` does not** (`widgets.go:94`), so a looping effect checks `c.Preferences().ReduceMotion` itself.
- Menus stay native: `Element.Menu` and `Element.ContextMenu` are not wrapped.
- No new module dependencies.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Reduce motion.** Under `ReduceMotion` the Skeleton does not pulse: two images 300 ms apart are identical. Pinned in Task 4 (`TestKitSkeletonStillUnderReduceMotion`).
2. **Disabled controls.** A disabled Button or IconButton neither changes its background on hover nor clicks. Pinned in Task 2 (`TestKitButtonDisabledInert`).
3. **Selected rows.** A selected SidebarItem/RailButton/Pressable does not fire its click; an unselected one does. Pinned in Task 3 (`TestKitSelectedDoesNotClick`).
4. **Keyboard users get the tooltip.** Focusing the anchor with Tab shows the tip at once, and the anchor keeps its own label. Pinned in Task 3 (`TestKitTooltipOnFocus`).
5. **Folded state survives the migration.** The mail sidebar's account fold and Wit's tool-call disclosure keep their per-key state across frames and page changes once they are `kit.Collapsible`. Pinned in Task 6 (`TestAccountFoldPersists`, `TestToolDisclosurePersists`).
