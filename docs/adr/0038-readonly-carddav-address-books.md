# 只读 CardDAV 通讯录：列表按名片归并、补全按地址展开，头像同步期落库

演进 [0029](0029-contacts-derived-from-mail.md)：Godwit 自身依然不提供新建或编辑联系人的表单，但允许在设置中独立于邮件账户接入标准 CardDAV 通讯录作为只读数据源，按子地址簿启停并通过 `sync-token` 增量缓存到本地 SQLite。

名片与邮件往来在联系人页和 ⌘K 搜索中按共享邮箱归并为一个联系人（冲突字段按设置中的通讯录顺序取优先），以便查看同一人跨邮箱的完整往来并避免「通讯录」分类出现同名重影；写信补全则仍按单个邮箱地址展开。通讯录名称仅在邮件 `From` 头无显示名时为收件箱和阅读器兜底，不覆盖带人名的动态通知头。名片 `PHOTO`（含外部 URI）一律在后台通讯录同步阶段校验落库，阅读邮件时零联网，故不受单封邮件远程图片 `ask` 门控限制，但在垃圾邮件与欺诈伪造（`SecurityFraud`）邮件上隐藏以防冒充；通讯录地址也不自动视为远程图片受信任发件人或已确认转发收件人。内置 Wit 与 `godwit mcp` 开放零出站的只读联系人查询工具。
