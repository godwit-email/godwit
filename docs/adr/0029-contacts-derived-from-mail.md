# 联系人从邮件整理，只读

「联系人」是和邮件、Wit 平级的顶层页面，但联系人不单独保存：每次都从本机已同步的邮件按地址（`AddrKey`）整理出来，跨账户合并，不含用户自己的账户。所以联系人不能新建、编辑、删除，也不和 CardDAV、Google、iCloud 等外部通讯录同步；同一个人的几个地址算几个联系人。⌘K 搜索里的「联系人」分组用的是同一套整理。

联系人页上的退订、全部归档、屏蔽都是用户每次亲手触发的操作，不会变成「这个发件人以后都这样处理」的规则，所以不违反 [0014](0014-labels-local-manual-wins.md)。退订照旧只认邮件头（见 GLOSSARY「一键退订」），mailto 退订只生成草稿（[0003](0003-no-extension-can-send.md)）。

## Considered Options

单独建一张可编辑的联系人表，可以改名、合并地址，但要处理它和邮件不一致的情况，现在没有这个需求。等邮件多到每次整理变慢时，再加一张由邮件推导的缓存表，它仍然只读。
