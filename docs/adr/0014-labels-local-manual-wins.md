# 标签只存本地，手动永远优先

邮件标签只存在本地，不同步到服务器。每个标签有一个建好后不再改的 `slug`，为以后同步成 IMAP 关键字留好身份；预置标签用英文 slug（如 `otp`），用户新建的由 `u` 加 id 生成。预置标签的名称和说明按首次启动时的界面语言写入，之后不随语言切换，因为它们已经是用户的数据。

手动操作永远优先于模型：用户手动加的标签不会被分类器删掉，手动去掉的（记为 `source=manual, active=0`）不会被加回来，回扫时也一样。分类器遇到某封邮件已有手动记录的标签，直接不出这道题。

## Considered Options

不做按发件人等确定规则打标签，不做改了标签后自动回扫，不给已发送、草稿、垃圾邮件分类。
