# 模型服务用不变的 slug 引用

skill、Action 和设置里统一用 `服务/模型 ID` 引用模型，其中「服务」是创建时由名称生成的 slug，之后不随改名变化。这些引用会写进用户自己的 skill 文件，改名不能让它们失效。

## Consequences

- slug 不能和其他服务的 slug、名称或旧名重复；服务名称也不能取其他服务的 slug 或旧名。
- 升级时每个服务当时的名称记为旧名（别名）：解析时找不到 slug 再按旧名精确匹配。当前名称不参与解析；服务删除后旧名随之失效，不会转指其他服务。
- `plugin/` 前缀留给插件模型（见 [0020](0020-plugin-models-host-sdk.md)），模型服务不会再分到 slug `plugin`。
