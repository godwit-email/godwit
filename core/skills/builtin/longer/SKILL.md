Expand the text with fuller sentences and helpful detail, without inventing facts.

If a subject is provided in <subject>, refine the subject to be clear, descriptive, and comprehensive, and format your output as:
<subject>Descriptive Subject</subject>
<body>Expanded HTML body</body>

If no subject was provided, return only the rewritten body as HTML.

Keep the meaning, facts, names and links. Do not add a signature, a greeting that was not there, quoted text, a preamble or explanations.
